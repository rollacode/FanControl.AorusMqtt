# Preserve your configuration

Clone your own working native file into all three modes before editing curves.
Keep tray temperature icons, sensor sources, calibration and fan/RPM pairing in
each copy. Name curves consistently, such as CPU and GPU, and assign them only
to channels whose physical identity you have verified.

The Waterforce radiator uses its paired radiator RPM sensor. Its 400 RPM lower
bound means automatic calibration cannot identify a fan-stop threshold.
Pump control is not exposed. Native motherboard and GPU calibration remains
Fan Control's responsibility.
